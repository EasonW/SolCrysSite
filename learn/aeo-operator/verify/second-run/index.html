Your second run

Re-measure against a frozen prompt set, and read the per-prompt movement rather than the headline.

Conditions for a valid comparison

Three things must be true. The prompt set is unchanged from the baseline. Enough time has passed for the change to propagate — at least two weeks for a page edit, longer for anything off-domain. And you have written down in advance what would count as success.

If any is false, run anyway if you like, but be clear that you are collecting an observation rather than testing a hypothesis.

Read the prompt you targeted first

Your hypothesis named a specific prompt. Look at that one before the aggregate, because the aggregate blends the prompt you targeted with nine you did not touch, and that blend can easily hide or manufacture the effect.

Then read the actual response, not just whether the flag flipped. Sometimes the informative result is that you are now cited but still not recommended — which is not failure, it is progress to the next failure mode, and it tells you what the following cycle is about.
