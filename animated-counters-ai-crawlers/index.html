Animated stat counters can read 0 to AI crawlers: how to check and fix them

A count-up counter looks right in a browser, ticking from 0 to the real number as the visitor scrolls. Whether an AI engine reads that number depends on what's in the HTML underneath.

Updated 2026-11-02

Questions this guide answers

  • Can AI crawlers see animated number counters?
  • Why does my page source show 0 instead of my stat?
  • How do I make an Elementor counter readable to AI search?
  • Do Divi number counters show up for search engines?

Direct answer

If a stat on your page counts up as visitors scroll to it, check the HTML your server sends, because that's the copy a crawler that doesn't run JavaScript reads. Counters built with Elementor, Divi, and Kubio put a 0 or an empty slot there and keep the real number in an attribute that only their script reads.

To check, open the page's source and look at the number each counter shows as text, not the one in its attributes. To fix it, make the HTML carry the real number: in Elementor, set Starting number to the same value as Ending number; in Divi and Kubio, replace the counter with a text or heading block that shows the number.

Why crawlers can miss the number

A crawler that reads the HTML without running the script gets the placeholder, so a model working from that copy reads a stat like "40 hours saved per month" as "0 hours saved per month."

Google renders JavaScript but notes that "not all bots can run JavaScript," and OpenAI, Perplexity, and Anthropic don't say whether their crawlers do (how each engine fetches pages). A number that exists only after a script runs is one you can't count on an AI engine to read.

Check your pages

Start with the pages that carry your proof, such as the homepage, product and pricing pages, and case studies. On each one:

  • Open the source. In Chrome, type view-source: before the URL, or right-click and choose View Page Source. Don't use Inspect: it shows the page after scripts ran, so the real number appears there and hides the problem.
  • Find the counters. Search for data-to-value (Elementor), data-number-value (Divi), or data-kubio-component="counter" (Kubio). Each match is one counter.
  • Read the number it shows as text. That's the text inside the counter's tag; for Divi, inside its percent-value span. If that text isn't the real number, the counter needs the fix.
  • After the fix, reload the source and check that the real number now appears as text.
