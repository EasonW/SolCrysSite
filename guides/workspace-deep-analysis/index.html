Guide 03 · Planning improvements

Workspace Deep Analysis

See which prompts need work, find out why from the answers and the pages they cite, and turn the findings into a plan in Actions Hub.

PDF · 12 pages · 1.9 MB · October 2026

Open PDF (new tab) · Download PDF

Before you start.

Workspace Deep Analysis is available on every plan, and each analysis uses one Deep Analysis from your plan's monthly allowance. Each prompt needs at least one completed monitoring run in the last 14 days; three or more runs give a better result. If you still need to add prompts or run a measurement, start with Workspace Setup.

  2. Page 2: Check how each prompt is doing

    Read Volume, Mentions, Visibility SOV, and Recommendation for each prompt.

    Read page 2 as text

    SOLCRYS / STEP 1 · CHECK YOUR PROMPTS Check how each prompt is doing Prompt Analysis shows, for each question, how often AI answers mention you, which other brands they name and how well they recommend you. 1. Select Prompt Analysis in the sidebar. 2. Choose 14d and All. This is the same period Deep Analysis looks at. Use Filter or the search box to focus on a topic. 3. Read each row from left to right: Column What it tells you Volume How often people ask this question, estimated as High, Medium or Low. Mentions How many AI answers named your brand, out of all answers in the period. 9/9 means every answer named you. The small line shows the trend. Visibility SOV Your share of voice: the brands the answers name for this question, and how often. Your brand is highlighted. Recommendation When answers mention you, how strongly they recommend you, from 0 to 100, with a label such as Excellent, Good or Average. Answers that leave you out are not counted here. Analysis Analyze opens Deep Analysis with this prompt already selected (step 2). SolCrys | Workspace Deep Analysis 2 / 12

  3. Page 3: Find the prompts that need work

    Expand a prompt to compare engines, then note where a competitor leads or the recommendation is weak.

    Read page 3 as text

    SOLCRYS / STEP 1 · CHECK YOUR PROMPTS Find the prompts that need work Expand a row to see each engine's answers and recommendation score. 1. Select the arrow at the start of a row. Each AI engine gets its own line, with its number of answers and its recommendation score. 2. Read the dots. Each dot is one answer: filled when it mentions your brand, hollow when it doesn't, and red when it mentions you with a concern. The larger dot is the latest answer. 3. Select an engine's line to read its answers. 4. Note the prompts where a competitor leads, or where the recommendation is Average or lower. In this example, Clearview BI is named in 8 of 9 answers to the small-team question, Perplexity never mentions Northstar Analytics, and one Gemini answer raised a concern. When you want to know why Prompt Analysis shows where you stand. Deep Analysis reads the answers and the pages they cite to explain why, and turns what it finds into a plan. Prompt Analysis tells you Deep Analysis adds How often each engine mentions you, prompt by prompt Why: the sources and pages the answers rely on Which competitors the answers name What already works for you, and what holds you back How well the answers recommend you A dated plan of actions you can add to Actions Hub SolCrys | Workspace Deep Analysis 3 / 12

  4. Page 4: Start a Deep Analysis

    Choose the engines and up to 10 prompts, see why a prompt is unavailable, and start the analysis.

    Read page 4 as text

    SOLCRYS / STEP 2 · RUN DEEP ANALYSIS Start a Deep Analysis New analysis, with the unavailable prompt opened. Set up the analysis 1. On Prompt Analysis, select Deep Analysis at the top right. The panel opens beside the table, on New analysis. Or select Analyze on any prompt to open it with that prompt already selected. 2. Under Engines, keep the AI engines you want included, for example 3 of 3. 3. Under Prompts, recommended prompts are already selected. Add the ones you noted in step 1. One analysis covers up to 10 prompts, and the counter shows your picks, for example 5 of 10 selected. Select all picks the prompts shown, and Unselect all clears them. With more than 10 prompts, the list shows 10 per page. 4. Use Filter by prompt, category or persona to find a question. Each row shows its tags, volume and mentions. 5. Open 1 prompt can't be analyzed yet to see why a prompt isn't available, for example No completed monitoring runs in the last 14 days. 6. Select Start analysis. It usually takes 5 to 15 minutes, and you can leave the page. Pick prompts that belong together Results are strongest when the prompts ask about the same need, such as setup, pricing or comparisons. With up to 10 prompts, one analysis can cover a whole topic. Include a prompt where you already do well: what works there shows what to repeat. A prompt with fewer than 3 monitoring runs can still be picked. The panel notes that more runs give a better result. Each workspace analysis uses one Deep Analysis from your plan's monthly allowance. Only editors can start an analysis; everyone in the workspace can read the reports. SolCrys | Workspace Deep Analysis 4 / 12

  5. Page 5: Follow the analysis

    Track the run's steps, read the header button, and stop a run when you need to change it.

    Read page 5 as text

    SOLCRYS / STEP 2 · RUN DEEP ANALYSIS Follow the analysis While an analysis runs, the header button and the run card show the same step. 1. After Start analysis, a run card takes the place of the setup. It names the run by its engines and date, for example All engines · Oct 10, with its start time and number of prompts. 2. Follow the steps: Reading answers and cited pages (step 1), Writing the analysis (step 2), then Checking the analysis and publishing it (step 3). 3. Close the panel or leave the page whenever you like. The report waits under All reports. 4. Select Stop to cancel the run, for example to change its prompts or engines. Then start a new analysis. Read the header button State Button What it means Ready to start Opens the panel. With no analysis running, start on New analysis. Running An analysis is running. Select it to see the run card. Finished A report finished while you were away. Select it to open the report; the dot clears once you've seen it. If a run shows Didn't finish, open it to read why. If there was too much to read in one analysis, select Analyze again with fewer prompts. SolCrys | Workspace Deep Analysis 5 / 12

  6. Page 6: Read the verdict and what's working

    Read the report header, the mentions per engine, the verdict, and the sources that already help you.

    Read page 6 as text

    SOLCRYS / STEP 3 · SEE WHAT'S WORKING Read the verdict and what's working The report opens on Diagnosis: the header, mentions per engine, the verdict and what's working. Part What it tells you Report header Ready, then the workspace, market and date. The line under the name counts the prompts, answers and engines analyzed. Tabs Diagnosis; Actions, with its number of tasks; and Tracked cards, with the tasks already in Actions Hub. Engine bars For each engine, how many answers mention your brand, best engine first. 4 / 15 means 4 of 15 Perplexity answers named Northstar Analytics. Verdict One sentence that sums up the analysis. Read it before the details. What's working Sources that already help you, such as a roundup article that names your brand and that every engine cites. Keep them accurate and up to date. The bars count AI answers, not website visits. If no engine mentions your brand, Diagnosis shows No AI visibility for these prompts and lists every finding under what holds you back. Select the expand icon at the top of the panel for a full-width view, and Back to side panel to return. SolCrys | Workspace Deep Analysis 6 / 12

  7. Page 7: See what holds your brand back

    Read each finding's engines, type, and reach, and check the answers behind it.

    Read page 7 as text

    SOLCRYS / STEP 4 · SEE WHAT TO IMPROVE See what holds your brand back Each finding names its engines, type and reach, then shows the answers behind it. 1. Read the engine label above each finding, such as ALL ENGINES or CHATGPT · PERPLEXITY. Findings are grouped by the engines they come from. 2. Read the type and reach, for example Content gap · 2 of 5 prompts, then the finding itself. 3. Check the evidence. Each row shows the engine, the answer's own words, the prompt and, when there is one, the page the answer cited. Select Show 1 more for the rest. 4. Select a task under Addressed by to jump to the action that fixes it. Finding type What it means Content gap Answers need information that none of your pages gives, so they quote someone else. Competitor advantage Answers rely on sources that favor a competitor, such as the competitor's own comparison guides. Owned content not cited You have a relevant page, but answers don't cite it for these prompts. Citation source A page the answers cite. Under What's working, it already names your brand.   8. Page 8: Review the recommended actions

    Read where to publish, why, what to cover, and each task's effort and impact.

    Read page 8 as text

    SOLCRYS / STEP 5 · REVIEW THE ACTIONS Review the recommended actions The Actions tab sums up the plan in one sentence, then lists Week 1. Card part What it tells you Publish to Where the work goes. 1P Owned is your own website, 3P Editorial is another site's article or listing, and a platform name such as YouTube means a post there. New page or New post means it doesn't exist yet. Title The task in one line. Select it to fold or unfold the card. Why do this What the AI answers show, and why this page matters. Key points to cover What the page, listing or pitch should say. Kind The type of task, such as Page edit, New page, Listing, Pitch, Post or Case study, at the card's lower left. Effort, Impact Low, medium or high. Effort is how much work the task takes; impact is how much it could help. Point to Impact for a short reason. Potential impact The engines and the number of prompts the task could help. Select it to see those prompts. Add to Actions Sends the task to Actions Hub (step 6). The filled button marks the next Week 1 task you haven't added yet. SolCrys | Workspace Deep Analysis 8 / 12

  9. Page 9: See how the plan is organized

    See what Week 1 and Weeks 2–3 hold, how the dates are set, and what a note beside a destination means.

    Read page 9 as text

    SOLCRYS / STEP 5 · REVIEW THE ACTIONS See how the plan is organized The tasks are already in order, so you can start at the top and work down. Part of the plan What it holds Week 1 The tasks most likely to make a difference. Start here. Weeks 2–3 The remaining tasks, grouped by where you publish: 1P Owned (your own website), 3P Editorial (other sites) and UGC (social and video platforms). Weeks 2–3 opens from its heading. Each group lists its tasks. Dates follow the report: Week 1 is the 7 days from the day it finished, and Weeks 2–3 the 14 days after. That leaves the rest of the month for your changes to show up before your next analysis. A note beside a destination, such as publisher not confirmed or not cited yet, means we couldn't confirm it. Check that the site accepts listings or pitches before you start. SolCrys | Workspace Deep Analysis 9 / 12

  10. Page 10: Add planned actions to Actions Hub

    Add the tasks you plan to do, review tracked cards, and return to earlier reports.

    Read page 10 as text

    SOLCRYS / STEP 6 · ADD THEM TO ACTIONS HUB Add planned actions to Actions Hub After Add to Actions, the card shows In Actions Hub and an Open link. 1. Start with Week 1. Select Add to Actions on each task you plan to do. The card changes to In Actions Hub, and the plan's summary line counts the tasks added, for example 3 added to Actions Hub. 2. Add tasks from Weeks 2–3 when your team has room for them. Leave out any you decide not to do. 3. Open Tracked cards to see every task from this report and its status in Actions Hub. Tracked cards lists this report's tasks in Actions Hub, with their status. Come back to a report All reports, newest first. 4. Select All reports in the panel. Your reports are listed newest first, each with its engines, time, number of prompts and number of actions. Older single-prompt reports appear in the same list. 5. Select a row to open the report. Each report keeps the engines, prompts and evidence it ran with. SolCrys | Workspace Deep Analysis 10 / 12

  11. Page 11: Work on the actions

    Assign, review, and publish the work in Actions Hub, then measure the change next month.

    Read page 11 as text

    SOLCRYS / STEP 7 · WORK ON THEM Work on the actions Actions Hub shows each task's stage, owner and due date. Three days later, the Week 1 tasks are under way. 1. Select Open on a task card, or open Actions Hub in the sidebar. In List view, tasks from the analysis show Workspace Deep Analysis as their source. 2. Open a task to read its brief from the analysis: where to publish, the key points and the evidence behind it. 3. Set an owner, priority and due date where those controls are available. 4. Move the task through Todo, In Progress, In Review and Approved as the work moves along. In Board view, drag the card to its new column. 5. When the content is live, open Publish, enter the Published URL and choose Mark as Published. The task moves to Complete. Measure the change next month 6. About a month after your analysis, return to Prompt Analysis and compare Mentions and Recommendation for the prompts your tasks named. 7. Then run your monthly analysis: open the last report and select Analyze again to start a new analysis with the same engines. Compare it with the earlier report under All reports. Adding a task records planned work. It doesn't publish anything or guarantee a result; the next measurements show what changed. SolCrys | Workspace Deep Analysis 11 / 12

  12. Page 12: Quick reference and troubleshooting

    The monthly rhythm and the seven steps on one page, and what to check when a result needs explanation.

    Read page 12 as text

    SOLCRYS / QUICK REFERENCE The flow at a glance Once a month: run one analysis. During the month: review the actions and get them done. Next month: measure, then analyze again. 1. Check your prompts. On Prompt Analysis, choose 14d, read Mentions, Visibility SOV and Recommendation, and expand the rows that look weak. 2. Run Deep Analysis. Select Deep Analysis (or Analyze on a prompt), pick up to 10 prompts about the same need and select Start analysis. 3. See what's working. Read the verdict, the engine bars and What's working. 4. See what to improve. Read each finding under what holds your brand back, and check its evidence. 5. Review the actions. On Actions, read Week 1 first: where to publish, why, what to cover, effort and impact. 6. Add them to Actions Hub. Select Add to Actions on the tasks you plan to do. 7. Work on them. Assign owners and dates, publish, mark tasks published, then measure and analyze again next month. When a result needs explanation Question What to check A prompt can't be analyzed It needs a completed monitoring run in the last 14 days, and it must be active. Open the unavailable list for the reason. You can't pick another prompt One analysis covers up to 10 prompts. Uncheck one to pick another. Start analysis is unavailable Pick at least one engine and one prompt. Only editors can start an analysis. If your plan has no Deep Analyses left this month, the panel says so. The run says Didn't finish Open it for the reason. If there was too much to read, analyze again with fewer prompts. No actions this time No action passed our quality checks. The Diagnosis still applies, and the Actions tab explains why. A task you expected is missing The plan keeps the tasks most likely to make a difference. Check whether the answers analyzed cite the page you had in mind. Numbers differ from Prompt Analysis Deep Analysis reads only the prompts and engines you picked, over up to the last 14 days. A destination has a note publisher not confirmed or not cited yet: check that the site accepts the listing or pitch before you start. Findings describe the AI answers we measured and the pages they cite. They are not website traffic, and a task's impact is an estimate, not a promise of results.
